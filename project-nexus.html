Overview

"A game this simple has nowhere to hide. Every decision shows."

Nexus is Webtastic Games' first shipped title — a from-scratch rebuild of tic-tac-toe with five visual themes and an unbeatable minimax opponent. It exists to prove a small, deliberately constrained idea can still be built to a real standard: considered motion, a genuine AI opponent instead of a random one, and a visual system that changes the feel of the game without changing the rules.

Challenge

Tic-tac-toe is a solved game — with perfect play, it always ends in a draw. That's precisely what made it hard to design for. The brief wasn't "build tic-tac-toe," it was "make a solved game worth playing anyway." That meant the entire experience had to carry weight the ruleset couldn't: feel, pacing, visual identity, and an opponent that plays convincingly rather than randomly.

Research

We looked at how mobile game studios handle "solved" classics — checkers, connect four, chess openings — and found the pattern consistently: the ones that hold attention lean entirely on presentation and opponent quality, since the ruleset offers no fresh ground.

We also tested a dozen casual tic-tac-toe implementations already live on the web. Almost all used a random or lightly-weighted AI that could be beaten by accident. None had a theming system with real visual range rather than palette swaps.

Process

Development split into two parallel tracks from day one: the game engine (board state, win detection, the minimax opponent with alpha-beta pruning for instant response) and the presentation layer (five themes, each with its own motion timing, palette, and win-state animation). Keeping these decoupled meant a theme could be swapped without touching game logic, and the engine could be hardened without any visual regression risk.

Playtesting focused on one question: does the opponent feel smart within the first three moves? Early builds played optimally from move one, which read as robotic. The shipped version plays a wider opening book before tightening into perfect defensive play mid-game — closer to how a sharp human opponent actually plays.

Design System

Each of the five themes — Mono, Terminal, Paper, Neon Low, and Dusk — is a full token set: board color, mark color, grid weight, win-line animation, and sound-off haptic-style feedback via subtle motion. Themes share layout and spacing so switching never feels like a different app, only a different mood.

Development

The opponent runs minimax with alpha-beta pruning and a shallow opening-move randomizer, evaluated client-side in well under a frame — no server round-trip, no loading state between moves. The whole build ships as static assets, so it loads instantly and works offline once cached.

Results

Nexus shipped as Webtastic Games' proof of concept for the studio's actual thesis: small scope, real depth. It's the reference point every later Webtastic Games project gets measured against — if a mechanic can't hold up the way Nexus's opponent logic does, it isn't ready to ship.
